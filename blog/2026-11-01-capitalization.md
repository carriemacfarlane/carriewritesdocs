The new Strategic Naming Team was halfway through its first assignment. We were choosing a name for a feature that completes the first step of the customer billing process. We had identified *recurring assessments* as the core concept, so that’s what we’d call it. But should we capitalize *recurring assessments*?

Our goal was to choose a name that could be used consistently across documentation, support, and advertising. “Turn on the setting that allows you to automatically start the billing process every month” is a mouthful. No one would say all those words every time! “Turn on recurring assessments” (or, “Turn on Recurring Assessments”!) was concise and repeatable.

All features have to be called something, and capitalized names get noticed. But as the Intuit design system [points out](https://contentdesign.intuit.com/style-and-usage/formatting/#capitalization), if all features are capitalized, the user and the brand suffers. Imagine a paragraph where capital letters interrupt every sentence. It’s frustrating! When all features are capitalized, the impact of the most valuable features is weakened.

I appreciate systems designer [Scott Kubie’s reminder](https://kubie.co/blog/fighting-feature-names) that sometimes a chair is just a chair, not an Eames Lounger. But when our devs have worked really hard on a new feature, how can we tell that it's an Eames Lounger? Sometimes we realize only after the excitement of release that what we had was just a chair.

The Strategic Naming Team applied a style guide rule based on the Intuit guide: noteworthy features that help users complete significant tasks are capitalized, and commonplace features that help users complete minor tasks are not. The new feature helps some users complete one step in the billing process. Our marketing team didn’t plan to publicize it. This means it’s a minor task, and it’s not noteworthy. It’s *recurring assessments*.

### What I’m Working On

* Capitalization of feature names.

### Question

* When should a feature name be capitalized?

### Answer

* Noteworthy features that help users complete significant tasks are capitalized. Commonplace features that help users complete minor tasks are not capitalized.
