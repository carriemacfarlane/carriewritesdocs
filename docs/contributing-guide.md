# Contributing Guide

I created this contributing guide for [The Good Docs Project](https://thegooddocsproject.dev/), a group that builds templates and sample documentation for open source software developers. The fictional audience for the guide is contributors to a group called KronoPy. The real audience for the guide is software developers who want an example of this [contributing guide template](https://www.thegooddocsproject.dev/template/contributing-guide).
